# AI Invoice Image Processing System

此專案提供「AI 發票影像處理系統」的完整可實作藍圖，包含：

- 可擴展前後端分離架構
- PostgreSQL 資料表設計與 SQL DDL
- REST API 規格（OpenAPI）
- UI/UX 頁面與 Manual Review 三欄工作台設計
- 狀態流轉與商業規則
- 統一 JSON 輸出 Schema
- AI Prompt Engine 設計
- MVP 與 Phase 2 路線圖
